# Connexa Contact Management System

A full-stack Java + React contact management system built with Spring Boot, Spring Data JPA, SQL Server, and React.js.

## Features
- User registration and login
- Contact create, update, search, view, and delete
- Password change and profile management
- JWT authentication
- Global exception handling and Slf4J logging
- React frontend with responsive contact dashboard
- SonarQube integration support

## Structure
- `backend/` - Spring Boot application
- `frontend/` - React application

## Run
1. Start the backend: `cd backend && mvn spring-boot:run`
2. Start the frontend: `cd frontend && npm install && npm run dev`
